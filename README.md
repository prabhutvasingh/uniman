## 💡 The Philosophy

When users transition from Windows to Linux, they often carry the habit of avoiding built-in app stores (similar to avoiding the Microsoft Store) and instead prefer downloading standalone installers directly. **Uniman** bridges this gap by providing a familiar, guided installation experience on Linux, removing terminal friction for beginners.

---

## ✨ Features

- **Guided Experience** — Acts like a smooth Windows `.exe` installer workflow tailored for Linux.
- **Universal Multi-Distro Support** — Works across Arch Linux, Ubuntu, Fedora, Debian, and FreeBSD.
- **Live System Info** — Real-time system information displayed during installation.
- **Zero-Friction CLI & GUI** — Simple syntax to run installers instantly.

---

## 🚀 Usage

Run Uniman from the terminal:

```bash
python3 uniman.py [PACKAGE-NAME]
```
